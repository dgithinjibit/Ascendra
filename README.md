## 🏗️ Architecture
- **Frontend**: Next.js 14 + TypeScript + Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Real-time + Auth)
- **AI**: Omega Agent (Neuro-symbolic decision making)
- **Cache**: Redis (Cross-device session sync)
- **Future**: AWS integration with SageMaker + Bedrock + Personalize

Built for Kenyan Grade 2 students with CBC curriculum alignment and cultural context.
